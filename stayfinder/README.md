# StayFinder

## What it is
A hotel/accommodation discovery and comparison interface.

## Common use
Hotel booking, travel accommodation search and tourism portals.

## Why it is relevant
Booking UIs need strong search, filtering, price visibility, amenities and clear calls to action.

## What this implementation adds
This template supports price/rating/amenity filters, sorting, responsive hotel cards and a booking-details modal.

## Run
Open `index.html` in a modern browser.
