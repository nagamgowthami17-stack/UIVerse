# Online Course Platform

## UI Pattern
A course discovery and enrollment interface with searchable course cards and course information.

## Common Uses
MOOC platforms, professional learning websites, training portals, and educational marketplaces.

## Modern Relevance
Search, category filters, ratings, instructor details, pricing, and clear enrollment actions are common patterns in modern learning platforms.

## Implemented Features
- Navigation bar
- Course search
- Category filters
- Course cards
- Instructor information
- Ratings
- Pricing
- Enrollment actions
- Course details
- Responsive design

## Technologies
HTML5, CSS3, JavaScript.
