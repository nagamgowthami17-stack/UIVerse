# UI Template Collection Hackathon
## GitHub Workflow

## 📌 Project Overview

This project is a modern **Web UI Template Collection** focused on **Healthcare and Education** interfaces.

The project has two main objectives:

1. Learn and demonstrate the GitHub workflow using **Fork, Clone, Branch, Commit, Push, Pull Request, Code Review, and Merge**.
2. Build modern, responsive, and interactive UI templates using **HTML, CSS, and JavaScript**.

The collection contains four application-style UI templates:

- Patient Health Dashboard
- Doctor Appointment & Booking
- Student Learning Dashboard
- Online Course Platform

The templates are designed as complete application screens rather than simple static pages.

# 🔀 GitHub Workflow

I follow this GitHub workflow:

**Fork → Clone → Branch → Develop → Commit → Push → Pull Request → Review → Merge**

### Workflow followed

1. Fork the assigned repository.
2. Clone the fork locally.
3. Create a separate branch for the contribution.
4. Develop the UI.
5. Test the implementation.
6. Commit with a meaningful commit message.
7. Push the branch to the fork.
8. Create a Pull Request.
9. Review the Pull Request.
10. Make requested changes if necessary.
11. Merge the approved Pull Request.

Project changes are developed on a separate branch instead of directly on the main branch.

# ▶️ How to Run

1. Clone or download the repository.
2. Open the project folder in VS Code.
3. Open `index.html` in a modern browser.
4. Select any of the four UI templates from the home page.

Alternatively, use the **Live Server** extension in VS Code for a better development experience.
