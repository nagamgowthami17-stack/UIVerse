# TravelMate

## What it is
An active-trip dashboard for travelers who are already on a journey.

## Common use
Travel companion apps, trip dashboards and post-booking travel management.

## Why it is relevant
Travelers need quick access to today's itinerary, spending, bookings, weather and important actions in one place.

## What this implementation adds
This template includes a live-feeling day timeline, budget progress, expense entry, checklist and contextual smart suggestion.

## Run
Open `index.html` in a modern browser.
