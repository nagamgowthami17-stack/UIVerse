# TripCraft

## What it is
An interactive itinerary builder for creating a day-by-day travel plan.

## Common use
Trip planning, itinerary management, travel agencies and personal travel organizers.

## Why it is relevant
Travelers need a clear view of time, activities and sequence. Timeline-based planning reduces cognitive load compared with long text lists.

## What this implementation adds
Day tabs, editable activities, traveler controls, interests and a simple optimization interaction are implemented with vanilla JavaScript.

## Run
Open `index.html` in a modern browser.
